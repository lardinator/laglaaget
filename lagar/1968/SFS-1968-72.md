# Kungörelse (1968:72) angående underrättelse om dom i mål om
ansvar för brott mot narkotikastrafflagen m.m.


Domstol, som meddelar dom i mål om ansvar för brott mot 
narkotikastrafflagen eller eljest för brottsligt förfarande med 
narkotika, skall så snart det kan ske sända avskrift av domen till 
socialstyrelsen.
